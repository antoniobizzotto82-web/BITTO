# BITTO — Bizzotto TV Familiar

Aplicación Android/Android TV con foto familiar, acceso a YouTube, categorías IPTV y reproductor Media3.

Las listas incluidas en esta versión usan plataformas y señales públicas/oficiales o enlaces a sus plataformas oficiales. Los servicios de pago, como ESPN dentro de Disney+ Premium, se abren en su plataforma oficial y requieren la suscripción correspondiente. No se incluyen credenciales ni streams no autorizados.

Categorías:
- Películas y Cine
- Deportes
- Infantiles y Noticias
- Te veo en vivo
